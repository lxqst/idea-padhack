# idpad / hackpad

idpad is a hackpad with 5 keys , one rottary encorder and an 128x32 oled display

it serves as my first ever self made electronics projekt.


## FEATURES;

- 128x32 oled screen
- rotary encorder
- 5 keys

## Firmware

The hackpad uses QMK Firmware

-The rotary encorder controlls the volumm and when pressed down it mutes everything
- the switches hafe following functions:
- skiping to the next song
- alt F4 shortcut
- snipping tool shortcut
- F13 button wich you can use for anything
- discord mute 


the oled display curently shows a pixel art picture
wich i may edit in the future





  
## BOM

- 5x Cherry MX Switches
- 5x Keycaps
- 4x heatset inserts
- 4x bolts
- 6x 1N4148 DO-35 Diodes
- 1x 0.91" 128x32 OLED Display
- 1x EC11 Rotary Encoder
- 1x XIAO RP2040
-  1x Case
